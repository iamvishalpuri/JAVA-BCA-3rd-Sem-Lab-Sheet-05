## Notes

- Each `.java` file intentionally contains **one public class** (matching file name).
- Supporting domain/application classes are **non-public** in the same file.
- **No interfaces are used** in these lab programs.
- Code is beginner-friendly and uses only standard Java (no external dependencies).
